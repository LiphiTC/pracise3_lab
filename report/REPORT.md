# Отчёт · Практика №3 · Вариант 3

Реализованы все три задания варианта 3 и интеграционная наземная станция.
Проверено 18.11.2026: Linux, GCC 16.2.1, CMake 4.4.4, Qt 6.12.0.

## Соответствие заданию

| Задание | Реализация |
| --- | --- |
| 1, вариант 3 | Quadcopter и FixedWingUAV, два Autopilot, общий QTimer 100 мс, имя в телеметрии, две группы меток |
| 2, вариант 3 | Круговые миссии, position_updated с креном, постоянные маркеры с setRotation, наращиваемые QPainterPath |
| 3, вариант 3 | Публичные команды взлёта / посадки / стопа, закрытый режим, цели 200 / 0 м, mode_changed |
| Интеграция | Таблица парка, Qt Charts, 2D и 3D сцены, PID, смена цели, журнал, отказы, восстановление |
| Архитектура | Модель на Qt Core без GUI и qDebug, указательные connect, QObject-владение, формулы только в модели |
| Три уровня аварии | Красный статус с причиной, журнал с временем, однократный QMessageBox до сброса |

Совместимость с Qt 5.15 предусмотрена в коде, но сборка проверена на Qt 6.12.0.

Скриншоты окна получены через Qt offscreen; 3D-кадр — отдельно через настоящий
OpenGL. Тесты ускоряют модель прямыми сигналами того же таймера, дополнительно
проверяя его реальную работу с интервалом 100 мс. Время на скриншотах — модельное.

Повторить захват 3D из каталога проекта при доступном X11:

```sh
QT_QPA_PLATFORM=xcb QT3D_RENDERER=opengl \
GROUNDSTATION_3D_CAPTURE="$PWD/report/screenshots/08_scene3d.png" \
  ./build/groundstation_window_tests
```
